# ADR-0001：編輯語義允許模式 A／B，優先 A

- 狀態：已接受（計畫書 v1.1）
- 日期：2026-10-12
- 需人工確認：否（已確認決策）

## 背景

修改 PDF 既有文字有兩種做法：

- **模式 A（就地改寫）**：在原內容串流中改寫 Tj／TJ 運算元，沿用原字型與座標。排版保真最高，
  但子集字型若缺新字的字形就無法表達。
- **模式 B（移除後重繪）**：移除舊文字的繪製指令，再以可嵌入字型在原位重繪新文字。可處理缺字，
  但字型可能與原文不同，且若只「蓋掉」而未移除，舊文字仍可被擷取（資訊殘留）。

繁中文件普遍使用子集 CID 字型，模式 A 的覆蓋率是 G2 的最大風險。

## 決策

1. 預設走模式 A。
2. 僅當 A 因子集字型缺字無法處理時才走 B，並在 EditPlan 標示模式與原因。
3. 模式 B 必須**證明舊內容已從內容串流移除**（非白底覆蓋），作為 G2 第 5 點驗收條件：
   以擷取工具在儲存後的檔案中找不到舊字串，且舊 Tj／TJ 運算子已不存在。
4. 不採用白底遮蓋、轉圖片等會殘留舊資訊或失去文字層的作法。

## 後果

- P2 先完成模式 A 與證據報告，再做 B 的子集。
- fixture S04（嵌入子集 CJK）、H02–H04、H16–H17 為主要判定樣本。
- 11/10 G2 決策點依 A 的實測覆蓋率決定繼續、收縮支援矩陣或停止。
