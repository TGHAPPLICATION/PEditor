# ADR-0032：頁面上的半透明編輯框，只有「套用」（取消預覽與前後對照）

- 狀態：已接受（2026-11-24，工程師要求「原本要點選預覽再套用，操作上不直覺；改為點選後顯示半透明編輯區，焦點自動跳到文字輸入欄，
  不需要預覽，只有一個套用按鈕，按完就寫回顯示畫面並關閉編輯框」；並選擇「有提醒時先問一次」「右側面板整個拿掉」）
- 日期：2026-11-24
- 決策者：工程師
- 取代：ADR-0021 的「預覽 → 套用」兩段流程與前後對照圖；P8 浮動編輯面板（G8-06 的面板部分）

## 決策

1. **編輯框在頁面上**：點選文字、儲存格（含手動選格）或圖片後，在選取內容正下方（下方放不下改上方）開半透明編輯框，
   不超出頁面可視範圍，捲動與縮放時跟著移動。焦點自動到輸入欄並全選原文字；圖片則焦點在「選擇新圖片…」。
   框內：選取內容（唯讀）、儲存格多行時的行選擇、新文字（或選擇新圖片與檔名）、「套用」、「×」。Esc 或「×」關閉、不修改。
2. **一個「套用」**：「套用」或 Enter（IME 組字中不送出，G4-02 不變）→ 規劃 → 沒有提醒就直接寫回、重新顯示頁面、關閉編輯框、
   焦點回到頁面（之後 Ctrl+Z 是文件復原，P4 U12 不變）。不再產生前後對照圖。
3. **有提醒先問一次**：計畫可套用但帶提醒（例如字型替換為 Noto Sans TC、圖片比例不同、空白格）時，不寫回，
   在編輯框內顯示提醒，按鈕改為「確認套用」，再按一次才寫回。提醒顯示後又改了內容，回到「套用」並重新規劃（不沿用舊計畫）。
   只是告知的訊息（「已同步更新結構樹 /ActualText」）不詢問。
4. **不能改**：能力判定不支援或計畫不可套用（例如溢出）時，原因顯示在編輯框內，「套用」停用或保持開啟讓使用者修改文字。
5. **右側編輯面板移除**：「檢視 → 編輯面板」一併移除。
6. 核心語義不變：仍由 worker 規劃與寫入，寫入後驗證（spec §8）；每次套用都可 undo／redo；另存流程不變。

## 後果

- spec §P4 的「前後對照」改為「套用後直接寫回頁面＋提醒確認＋可復原」；`preview_edit` API 保留（服務層與測試仍用），UI 不再呼叫。
- 改錯時以 Ctrl+Z 復原，代替套用前的前後對照。
- 測試：`tests/gui/test_e2e.py`（編輯框位置、焦點、Enter 套用、Esc 關閉、有提醒先確認、改字後重新規劃、告知訊息不問）、
  `tests/gui/test_layout.py`（無面板、小視窗內編輯框與「套用」可見）、`test_cell_ui.py`、`test_image_ui.py`、`test_ime.py`、`test_fonts.py`。
