# ADR-0030：多個 PEditor 視窗同時執行，視窗顯示目前檔名

- 狀態：已接受（2026-11-24，工程師選擇「允許多開 PEditor 視窗，開檔時在選單上顯示檔名以資區別」，取代分頁方案）
- 日期：2026-11-24
- 決策者：工程師

## 背景

工程師想同時處理多個 PDF。評估後分頁（同一視窗多份文件）需重構主視窗約 60 處單一文件狀態，約 3～5 人日；
多視窗則每個視窗一個行程與 worker，不改編輯流程。P4 U10 已讓暫存紀錄檔可跨行程共用（`transaction._registry_lock`），
但復原草稿沒有：第二個視窗啟動時會把第一個視窗**正在編輯**的文件草稿列為「可復原」，選「捨棄」會刪掉它。

## 決策

1. **開新視窗**：「檔案 → 開新視窗」（Ctrl+N）另啟一個 PEditor 行程（打包後為執行檔本身，開發環境為 `python -m peditor`；
   固定指令、不經 shell、不帶參數）。從開始功能表再開一次也同樣可行。
2. **草稿鎖**：開啟文件時取得該文件草稿的作業系統檔案鎖（`<draft_id>.lock`，Windows `msvcrt.locking`、其他 `fcntl.flock`），
   正常關閉或程式結束時放開。被別的行程持有的草稿：不列出、不可捨棄、不會被 purge 刪除。
   當機或強制結束時由作業系統釋放鎖，下次啟動即可復原（ADR-0020 §5 語義不變）。
3. **顯示檔名**：視窗標題為「檔名［ *］— PEditor 版本（建置）」（工作列與 Alt+Tab 同樣顯示）。不在選單列重複顯示（2026-11-24 工程師決定）。只顯示檔名，不顯示完整路徑。

## 後果

- 每個視窗各自一個 worker，記憶體隨視窗數增加；不設視窗數上限（由使用者自行控制）。
- 同一份檔案可在兩個視窗同時開啟編輯；各自另存為不同檔，原檔不會被覆寫（ADR-0020 §3）。不做跨視窗的開檔互斥。
