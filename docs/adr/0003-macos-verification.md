# ADR-0003：無 Mac 期間以 CI 證據達成 G0 的 macOS 驗證

- 狀態：已接受（2026-10-12，負責人確認）
- 日期：2026-10-12
- 需人工確認：否（已確認）

## 背景

目前沒有 macOS 實機。spec §6 P0 停止條件為「沒有 macOS 實機可驗證」，G0 要求「Windows 11 x64 與 macOS Apple Silicon 均啟動」，照字面 P0 即須停止。

## 選項

1. 立即購入 Mac mini M4 16 GB（NT$19,900）：P0 即有實機，但在 G2 決策前就支出。
2. **P0–P3 以 GitHub Actions macOS arm64 runner（macos-15，3 核 M1、7 GB）取得 CI 證據；
   P3 結束前（最晚 11/16）借用或購入實機**。
3. 雲端 Mac 租用：多有最低租期，長期累計高於購機。

## 決策

採選項 2。G0 停止條件改為「P3 結束時仍無 macOS 實機取得方案」。

| 驗證項目 | CI 可否取代實機 |
| --- | --- |
| P0 smoke build、空白 app 啟動 | 可（記為 CI 證據） |
| P1–P3 單元／整合、像素比對、crash injection | 可 |
| §8.3 效能基準 | 不可（runner 7 GB ≠ 基準 16 GB） |
| P4 IME、Cmd 快捷鍵、E2E | 不可 |
| P7 斷網與零出站 | 不可 |
| P8 乾淨機安裝、DMG | 不可 |

## 後果

- 報告中 CI 證據與實機證據分欄記錄；實機項目在取得 Mac 前一律 `NOT RUN`。
- 11/16 未取得實機方案 → 觸發停止條件，由人工決定。
- 先問借用；借不到再採購基本款，供之後相依更新回歸使用（維運成本最低）。
