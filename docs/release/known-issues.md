## 功能限制（依設計，拒絕而非誤改）

| # | 內容 | 來源 |
| --- | --- | --- |
| F1 | 文字編輯只支援單一橫排、同一 BT 內相鄰運算子；Form 內文字、直排、跨 BT 選取拒絕 | ADR-0018 |
| F2 | 新文字的字不在原字型子集時改用 Noto Sans TC（模式 B）；𠮷 等擴充區字回 GLYPH_MISSING | ADR-0008、ADR-0018 |
| F3 | 同一行以模式 B 改過後再改同一行拒絕（可先復原再改） | P6 §7 |
| F4 | 圖片替換只收 PNG 與 8 位元灰階／RGB JPEG；EXIF 方向只提示不轉正；ICC 不保留；Form 內、inline、旋轉、非矩形剪裁的圖片拒絕 | ADR-0022、P5 U4 |
| F5 | 半透明 PNG 以預乘遮罩嵌入，只以 MuPDF、PDFium 驗證；其他閱讀器邊緣顏色可能偏暗 | P5 U2 |
| F6 | 表格只認水平、垂直格線；旋轉表格、Form 內格線、只有底色的表格不自動偵測；不做列插刪、合併、跨頁重排、空白格補字 | ADR-0023 |
| F7 | 儲存格編輯偏保守：底色塊、比文字長的刪除線、曲線、斜線、蓋在文字上的註解會使該行不能改或不能長過它們 | ADR-0023 後果、P6 U6、P6 U7 |
| F8 | 加密、簽章、PDF/A、XFA、含主動內容（JavaScript、Launch、嵌入檔）的文件整份拒絕 | ADR-0007 |
| F9 | 單一串流解壓後超過 64 MB、影像宣告超過 50 MP、頁面運算子超過上限的頁面不能編輯 | ADR-0024 §3 |
| F12 | 新字變寬時同一行後面的字往右推（ADR-0028）；碰撞判定看不到行內影像（BI…EI）的位置，推字可能蓋到行內影像 | ADR-0028 §2 |
| F11 | 關閉視窗或開啟另一份檔案前會詢問「另存／不儲存／取消」（ADR-0027）；但套用或另存**進行中**關閉視窗時不詢問，該次修改可能遺失；復原草稿只在當機或強制結束後留下 | ADR-0020 §5、ADR-0027 |
| F10 | 沒有 ToUnicode 的 CID 字集字型（例如 Identity-H＋Adobe-CNS1 的標楷體）不能修改；面板顯示 MuPDF 擷取的文字僅供參考；使用者確認的整行替換（B3）列下一版 | ADR-0011、ADR-0026 |

## 安全殘餘

| # | 內容 | 來源 |
| --- | --- | --- |
| S1 | 非完整 OS 沙箱：worker 仍有使用者的檔案與網路權限；路徑白名單只在主行程層級，OS 出站封鎖只有監測沒有封鎖規則 | ADR-0024 §2、P7 U6 |
